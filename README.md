# Hector Valdes Hurtado

M.Sc. student in Geoinformatics and Spatial Data Science at the University of Münster. Background in mechanical, electronic and computer-systems engineering, with 5+ years of industry software development in Python and C++ (GE Aerospace, Ford).

## Focus

- UAV data acquisition, RTK-GNSS georeferencing and photogrammetry
- 3D reconstruction, point clouds and digital twins
- Machine learning and computer vision on aerial imagery
- Unity-based simulation for human-drone interaction

- **Indoor rescue drone:** low-cost, GPS-free drone prototype for 2.5D mapping (early stage).
- **GPR processing:** preprocessing pipeline and YOLO-based hyperbola detection on simulated and real B-scans.
- **Student research assistant, ifgi:** VR/AR and Unity WebGL experimental environment for a Marie Skłodowska-Curie Doctoral Network.
